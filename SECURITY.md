# Security Policy

This is a public visual and performance experiment. It must not receive, upload or persist sensitive information.

Do not commit API keys, access tokens, cookies, sessions, `.env` files, private endpoints, database connections, user records, real orders, real conversations, internal operations data, private product documents, identifiable performance reports or unlicensed assets.

Performance reports are generated and exported locally in the browser. They do not include IP addresses, cookies, tokens, precise geolocation, WeChat identity or real business data.

If a credential is exposed, revoke it immediately, remove it from the repository and rewrite the new repository history before any further publication. Report security concerns through a private channel rather than a public issue when disclosure would expose sensitive data.
